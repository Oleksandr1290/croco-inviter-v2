# 🐊 Croco Inviter — бот управления (Cloudflare Workers, бесплатно)

Панель управления: тексты, настройки, база ID. Данные в Cloudflare D1.
Работу от имени аккаунта (рассылка, ответы, архив/папка, подгрузка) делает программа agent.py
на ПК или сервере — она берёт данные из этой же базы.

Секреты Worker'а: BOT_TOKEN, ADMIN_ID, WEBHOOK_SECRET
